\begin{corollary*}[A Set Has a Maximum If and Only If Its Supremum Belongs to the Set]
Let $A\subseteq\mathbb{R}$ be nonempty and bounded above, and let $s=\sup A$.
Then $A$ has a maximum if and only if $s\in A$, and when this holds,
$\max A=s$.
\end{corollary*}
